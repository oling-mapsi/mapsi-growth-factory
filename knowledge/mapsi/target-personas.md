# Personas cibles MAPSI

Les personas MAPSI utilisables dans cette base minimale doivent rester derives des roles visibles dans les payloads et tests du projet.

- `manager` : role explicitement present dans les exemples de `product_changes` Courbex.
- `administrator` : role explicite dans les exemples de `product_changes` Courbex.
- `responsable` : role editorial prudent pour l'export du tableau utilisateur, directement deduit du resume "les responsables peuvent exporter...".

Ne pas inventer de segmentation plus fine tant qu'elle n'est pas appuyee par les contrats, segments ou historiques versionnes.
