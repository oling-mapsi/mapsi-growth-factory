# Terminologie MAPSI

- `feature_id` : identifiant editorial stable d'une fonctionnalite exploitable par le moteur.
- `module` : zone fonctionnelle ou capability associee a la fonctionnalite.
- `product change` : changement produit importe via le contrat MAPSI versionne.
- `source reference` : fichier versionne ou reference de contrat servant de preuve.
- `communication enabled` : drapeau autorisant l'exploitation editoriale du sujet.
- `minimum repeat delay` : delai minimal entre deux reutilisations editoriales d'un meme sujet.

Employer un vocabulaire descriptif et verifier chaque formulation sur les sources versionnees avant toute publication.
