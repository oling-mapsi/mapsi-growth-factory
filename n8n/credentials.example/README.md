Configurer n8n avec des variables d'environnement uniquement.

Variables minimales :

- `N8N_GROWTH_BASE_URL=https://growth-api.example.internal`
- `N8N_GROWTH_API_KEY=change-me`
- `N8N_MAPSI_INSTANCE_ID=gpmlm`
- `N8N_CAMPAIGN_ID=campaign-placeholder`
- `N8N_SANDBOX_MODE=true`
- `N8N_MAILPIT_BASE_URL=http://mailpit:8025`
- `N8N_MAUTIC_BASE_URL=http://mautic-mock:8020`

Ne jamais exporter de secret reel dans les JSON de workflow.
